# Draftly — React MVP

Первоначальная версия интерфейса AI-помощника для создания черновиков объявлений Авито в категории «Услуги».

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Сборка: `npm run build`.

## Что работает

- Демо-вход, локальные регистрация и авторизация (не серверная аутентификация).
- Обзор, статистика, навигация.
- Ввод текста и демонстрационный поиск нескольких услуг по ключевым словам.
- Редактирование, исключение и выбор услуг, изменение микрокатегории.
- Генерация отдельных демонстрационных объявлений и их предварительный просмотр.
- Сохранение, редактирование, удаление, поиск и копирование черновиков.
- Состояние сохраняется в `localStorage`, адаптивная вёрстка.

**Важно:** локальная авторизация не обеспечивает безопасность; логин и email сохраняются только в браузере, пароль не сохраняется и не проверяется сервером. Локальный классификатор — иллюстрация UX, а не ML-модель. Категории в нём демонстрационные; перед запуском нужно использовать официальный справочник категорий Авито. Не использовать эту сборку как production-сервис без бэкенда и полноценной авторизации.

## Интеграция со Spring Boot + Python

Фронтенд взаимодействует только со Spring Boot и использует контракт из корневого файла `API.md`. Клиентский адаптер расположен в `src/api.js`.

При создании анализа клиент вызывает `POST /api/v1/analyses`, затем опрашивает `GET /api/v1/analyses/{analysisId}` до завершения обработки. Перед показом объявлений выбранные классификации подтверждаются через `PATCH /api/v1/analyses/{analysisId}/services/{serviceId}/classification`. При изменении категории черновики перегенерируются и загружаются через связанные эндпоинты услуги.

Поиск категорий выполняется через `GET /api/v1/catalog/categories`, редактирование — через `PATCH /api/v1/drafts/{draftId}`, а подготовка текста для копирования — через `GET /api/v1/analyses/{analysisId}/export`.

Если `VITE_API_BASE_URL` пуст, используется `src/mockApi.js`. Сохранённый список черновиков, их локальное удаление, отметка «Готово» и демонстрационная авторизация пока остаются в `localStorage`.

Создайте файл `.env` на основе `.env.example` и укажите `VITE_API_BASE_URL=http://localhost:8080` при подключении бэкенда. Настройте CORS на Spring Boot или proxy в Vite.
