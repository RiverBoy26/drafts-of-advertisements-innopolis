# Draftly — фронтенд

React-интерфейс для анализа исходного объявления и работы с черновиками через Spring Boot API.

CSV-загрузка принимает столбцы `id,description` или `testcase,description` (в том числе описания с переносами строк). Если описание длиннее 10 000 символов, интерфейс предупреждает об этом и отправляет на анализ только первые 10 000 символов, поскольку это предел бэкенда и ai-service.

## Запуск

1. Запустите бэкенд по инструкции в `backend/README.md`.
2. В каталоге `frontend` выполните `npm install` и `npm run dev`.
3. Откройте адрес Vite (обычно `http://localhost:5173`).

По умолчанию фронтенд обращается к `http://localhost:8080`. Для другого адреса задайте `VITE_API_BASE_URL` в `.env` (пример — `.env.example`). Бэкенд разрешает CORS с `http://localhost:5173` по умолчанию.

Для запуска в Docker используйте `docker compose up -d --build` из корня проекта. Фронтенд будет доступен по `http://localhost:3000`. Переменная `VITE_API_BASE_URL` для контейнерной сборки задаётся в корневом `.env`; это адрес API, доступный **браузеру**.

При открытии `http://localhost:3000` отображается страница авторизации по адресу `/login`. После входа открывается главная страница. Повторное открытие или обновление сайта снова требует входа.

Регистрация, вход, каталог микрокатегорий, анализ, сохранение предложений, редактирование, перенос в «Мои объявления» и удаление выполняются через API. Список черновиков загружается с сервера после входа. Сессия хранится в памяти вкладки; исходные объявления и черновики загружаются с сервера.

Compose запускает Python ML-сервис вместе с бэкендом. При сборке Docker обучает CPU-модель из данных проекта; отдельный файл весов для запуска Compose не требуется. Без ключа DeepSeek сервис возвращает категории с пустыми заголовком и текстом, которые можно заполнить в интерфейсе. Копирование текста выполняется браузером и не требует API.
