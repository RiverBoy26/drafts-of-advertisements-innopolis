# Настройки ансамбля классификации объявлений

Для актуального кандидата используется локальный CPU + RuBERT ансамбль. Файл `.env.example` содержит значения по умолчанию; веса в Git не хранятся и распаковываются из отдельного архива.

## Веса и запуск

Скопируйте CPU файл в `ai-service/artifacts/cpu_char_conflict_resolved.joblib`, а содержимое каталога RuBERT — в `ai-service/artifacts/rubert_conflict_resolved/`. Затем заполните `.env` значениями из `.env.example` и запустите сервис обычным способом.

Если новые веса не распакованы, сервис не сможет загрузить заданный CPU артефакт. Для отката укажите ранее использовавшиеся `cpu_char_noise1024.joblib` и `rubert_base` в `.env`.

## Логика классификации

- Источник объявления: категория `101`; предсказываются дополнительные категории `102–106`.
- CPU модель использует символьный TF-IDF (3–5-граммы) и One-vs-Rest Logistic Regression.
- RuBERT читает длинные объявления окнами до 512 токенов с перекрытием 128 токенов. Для каждого класса берётся максимальная вероятность по окнам.
- Короткое объявление (до 512 токенов включительно): 45% CPU + 55% RuBERT.
- Длинное объявление: 55% CPU + 45% RuBERT.
- Порог для каждого класса — `0.525`; затем применяется проверка явного отрицания услуги.
- Пустой список категорий означает, что уверенность не превысила порог ни по одной категории `102–106`.

## Проверенные показатели кандидата

На отдельной ручной выборке из 19 объявлений: micro-F1 `0.9091`, precision `0.8333`, recall `1.0000`, exact match `0.7368`. На 800 OOD примерах — 1 объявление с ложным срабатыванием (`0.125%`). Предыдущая версия на той же проверке дала такой же micro-F1 и 2 ложных срабатывания на OOD.

Тёплая классификация измерена на RTX 3050 на 100 объявлениях: p50 `15.35 мс`, p95 `62.34 мс`, среднее `36.26 мс` на объявление. Загрузка CPU и RuBERT весов заняла около `8.31 с`. Измерение включает нормализацию, обе модели, их смешивание и фильтр отрицаний; не включает запуск HTTP-сервера, сеть и генерацию текста.

Классификатор работает локально и не отправляет запросы к платным API: стоимость API вызовов классификации — `$0`. Энергопотребление компьютера не измерялось. Генерация черновика через DeepSeek — отдельная функция и оплачивается отдельно, если включена.

Эти показатели получены на небольшой ручной проверке и на авторском OOD наборе. Они не являются оценкой закрытого набора. Предыдущая отправка набрала 89%; у нового кандидата закрытая оценка неизвестна.
