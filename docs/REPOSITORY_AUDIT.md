# Аудит репозитория

Официальный кейс и справочник находятся в `work/organizer/innoglobalhack_avito/`; контрольный набор включает 208 записей, обучающий JSONL — 10 000 слабых автоматических меток. В проекте есть React frontend и минимальный Spring Boot 4 / Java 21 каркас. Публичного Java workflow, Python пакета и AI-контракта в исходниках не было. Командный `API.md` отсутствует в этой версии checkout; предыдущая схема с UUID/полем `text` несовместима с официальными `description` и целочисленным `mcId`.

Решение: отдельный FastAPI сервис в `ai-service/`, официальный контракт без дополнительных полей; Java остаётся владельцем публичного API, БД и задач. Никаких Java-файлов не изменено. Данные организаторов включены локально для обучения/аудита; public-test не используется для обучения или RAG.
