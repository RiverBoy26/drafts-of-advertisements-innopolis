# Политика RAG

RAG применяется только при генерации и фильтрует записи по `mcId`. Принимаются только JSONL записи `verified=true`, `origin=human_reviewed_author`; исключается совпадающий исходный текст. Retrieval ранжирует `source_facts` лексическим Jaccard. Public train/test не индексируются. В репозитории сейчас пустой `curated_rag_examples.jsonl`: авторские примеры не создавались, поскольку их нельзя честно выдать за проверенные человеком. Пустой индекс означает обычную генерацию по фактам без retrieval.
