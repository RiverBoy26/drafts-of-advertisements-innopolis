# Draftly — фронтенд

React-интерфейс для анализа исходного объявления и работы с черновиками через Spring Boot API.

## Запуск

1. Запустите бэкенд по инструкции в `backend/README.md`.
2. В каталоге `frontend` выполните `npm install` и `npm run dev`.
3. Откройте адрес Vite (обычно `http://localhost:5173`).

По умолчанию фронтенд обращается к `http://localhost:8080`. Для другого адреса задайте `VITE_API_BASE_URL` в `.env` (пример — `.env.example`). Бэкенд разрешает CORS с `http://localhost:5173` по умолчанию.

Для запуска в Docker используйте `docker compose up -d --build` из каталога `backend`. Фронтенд будет доступен по `http://localhost:3000`. Переменная `VITE_API_BASE_URL` для контейнерной сборки задаётся в `backend/.env`; это адрес API, доступный **браузеру**.

Регистрация, вход, каталог микрокатегорий, анализ, сохранение предложений, редактирование, перенос в «Мои объявления» и удаление выполняются через API. Список черновиков загружается с сервера после входа. В `localStorage` хранится только сессия с токенами; исходные объявления и черновики там больше не хранятся.

Для успешного анализа нужен отдельный ML-сервис, реализующий `POST /internal/v1/avito/drafts`. Без него бэкенд вернёт ошибку обработки `ML_UNAVAILABLE`, которую интерфейс покажет пользователю. Копирование текста выполняется браузером и не требует API.
