# Оценка качества генерации

Реальных live генераций для ручной оценки пока нет: `DEEPSEEK_API_KEY` отсутствует. G0 (без RAG), G1 (статические инструкции), G2 (Top-K RAG), G3 (RAG + post-validator), false claims rate и ручная оценка — `NOT_MEASURED`.

Для будущей слепой оценки на одинаковых исходных объявлениях каждой версии дать отдельный псевдоним, скрывающий вариант. Рубрика 0/1/2: фактологичность; соответствие выбранной категории; сохранение полезных деталей; самостоятельность/читабельность; отсутствие утверждения про отдельный заказ без подтверждения. Отдельно фиксировать каждое unsupported factual claim. Примеры должны быть новыми, не train/public-test и не должны попасть в RAG-банк.

Автоматические guardrails в текущем сервисе проверяют формат, целевой ID, категорийные слова, точные evidence offsets, числа, часть ценовых/временных/географических обещаний, гарантий, скидок и лицензий. Дополнительная проверка claims через DeepSeek подключается `CLAIM_VERIFIER_ENABLED=true`; при ошибке она действует fail-closed, но увеличивает стоимость и задержку. По умолчанию выключена до оценки пользы. Ни детерминированная проверка, ни LLM-проверка не доказывает фактическую корректность; ручная оценка не проводилась.
