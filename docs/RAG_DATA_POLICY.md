# Политика RAG

RAG применяется только при генерации и фильтрует записи по `mcId`. Принимаются JSONL записи `verified=true` с происхождением `human_reviewed_author` либо `organizer_official_example`; исключается совпадающий исходный текст. Retrieval ранжирует `source_facts` лексическим Jaccard. Примеры служат только образцами структуры и формулировки, никогда источником фактов о новом исполнителе. Public train/test не индексируются: они содержат слабые метки и мусорные вставки. В индексе есть только официальный пример организаторов для категории 104; для остальных категорий retrieval пока пустой до проверки качественных примеров.
